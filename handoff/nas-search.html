Why this exists

Everyone on the team needs to find footage and photos fast, and nobody should have to scroll through folders or ask Kirk. Your Claude can search a list of every file on the NAS, then tell you where it is.

A list of file names, folders and tags

Plain truth about how it connects

The NAS itself is not connected to Claude. From outside the office it only opens through the UGREEN app or a browser login, so your Claude cannot see inside it, and that is the safe way: Claude never touches the real files. It only reads a copy of the file list (names, folders and tags, no photos or videos). It tells you the path, and you open the file yourself.

Copy this prompt

Paste it into Claude (claude.ai, Cowork or Claude Code), then attach file-index.json. Step 2 below shows where to get that file.

You are my Good Cup file finder. I attached file-index.json. It is a list of every file on the Good Cup NAS: names, folders, tags and notes only. It does not contain the files themselves.

How to work:
1. Treat file-index.json as your ONLY source of truth. Do not use the web, your memory or guesses about what we own. Never say a file exists unless it is a row in the index.
2. Before my first search, read the first rows and any key list inside the file, work out what each field means (its fields are name, path, type, farm, project, tags, people, place, yearMonth, description and score), and tell me in one line what you found. If folders are stored in a separate table, look up the real folder path from it.
3. When I ask for something in plain words, turn it into filters: type (photo, video, document, audio), farm, project, tags, place, year and usability (for example ready to use). Say which filters you used.
4. Show the 5 best matches. For each one give: the file name, the full folder path as it appears in the index, and one short line on why it matches (farm, project, tags, usability). Rank the most usable and most specific ones first.
5. If nothing matches, say "No match in the index" and suggest two other words or filters I could try. Never fill the list with weak guesses.
6. At the end of every answer, add one line with the date of the index (the file or the status note inside it shows it), and remind me that newer files may be missing. If the index looks older than a month, tell me to ask for a fresh one.
7. After the matches, tell me how to open the top result in the UGREEN NAS app: open the app, go to Files, open the GOOD CUP folder, then follow the folder path one folder at a time, then find the file name.
8. Never download, copy or move files in bulk, and never ask me to. The NAS is slow over the internet, so I will open or stream one file at a time, or queue what I need.
9. Keep answers short, in plain words, with no technical jargon.

Start by confirming you read the file, then ask me what I am looking for.

Using Claude Code on your Mac?

Paste this one instead. It saves the index in a folder on your Mac and builds a small search tool, so you can search again any time without attaching the file. Download the index from step 2 first, and keep it in your Downloads folder.

Set up a local Good Cup file finder for me. I downloaded file-index.json (the Good Cup NAS file list: names, folders and tags only) from the File search page and it is in my Downloads folder.

1. Create the folder ~/GoodCupFileIndex/ and move file-index.json into it. If a newer file-index.json is in Downloads later, replace the old one and keep the old as file-index-old.json.
2. Open the file, read the first rows and any key list, and work out what each field means (its fields are name, path, type, farm, project, tags, people, place, yearMonth, description and score). If folders are in a separate table, resolve them to real folder paths.
3. In ~/GoodCupFileIndex/ write a small Python 3 script called search.py that uses only the standard library. It takes plain words plus optional filters (--type photo|video|doc|audio, --farm, --project, --tag, --year, --usable) and prints the 5 best matches: file name, full folder path, and a short reason. It ranks matches that fit more words higher. If nothing matches it prints "No match in the index" and never guesses.
4. Run one test search for a farm name I give you and show me the output.
5. Every result ends with the index date and a note that newer files may be missing. Print how to open the top result: UGREEN NAS app, Files, open GOOD CUP, follow the folder path, find the file.
6. Rules: the index is the only data source. Never claim a file exists that is not in the index. Never mount, download, copy or move files from the NAS. It is slow over the internet, so I open one file at a time or queue it. Never write outside ~/GoodCupFileIndex/.

When it works, tell me the one command to run a search, for example: python3 ~/GoodCupFileIndex/search.py "bukidnon harvest" --type video

If something looks wrong

I cannot open the File search page

It needs a Good Cup Claude account. Sign in with your work email. If it still says no access, message Kirk.

I cannot find the Download button

Look for Download the index for Claude near the top of the File search page. If it is not there yet, tell Kirk, because the page may still be getting updated.

Claude cannot read the file

Try a new chat and attach the file again. If the file is very large, attach it in Claude on the web or use the Claude Code version.

The file Claude found is not in the app

The list is a copy from a past date, so newer or moved files may be missing. Tell Kirk the file name and he can refresh the list.

I need a whole folder of footage

Do not copy it all at once. The NAS is slow over the internet. Open or stream the clips you need, or ask Kirk to queue the copy.
